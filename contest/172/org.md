# A
Questão sobre valor esperado. Aparentemente tem solução
O(2 ^ n)
# B
Questão tranquila de dp em arvore, tem 3 estados
Estado que ignorou um caminho, outro
que ignorou o caminho atual, e outro que ignorou algum
caminho na subarvore

# C
Questão de contagem, a ideia é contar
o número de intervalos [l,r] em que
o valor minimo é a_l e o máximo é a_r

# D
A questão mais fácil até agora basicamente é 
contar o número de intervalos em uma string s
em que o número de aparições das letras é no máximo
um com exceção de um único elemento que tem que ser dois.
# E
Arvore, inverte estados dos nós filhos e atual, deixar todos
com estado desligado
# F
Questão de teoria dos números, como ele pede para contar
o número de valores de forma que gcd(x, N) = gcd(x + 1, N) = 1,
provavelmente envolve a phi de euler.

# G
Grafo funcional, basicamente é contar o número de pares do nós inciais
em que em algum momento dois
ponteiros podem ter o mesmo valor, sendo que ambos poder da yield
nó máximo uma vez no caminho.

# H
Contagem de subintervalo, xor dos elementos igual o maior elemento
no intervalos.
